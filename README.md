# HR-Analytics-Dashboard
This project is an advanced Power BI Dashboard" built on an HR dataset. It provides complete insights about employees and departments, including performance, attrition, and workforce diversity.
## 📊 Key Insights
- Total employees by year
- Leavers by year
- Attrition rate by year
- Department-wise employee count
- Age group diversification
- Tenure and attendance analytics

## 🛠 Tools Used
- Power BI Desktop (no Pro/Service required)
- DAX for calculated measures
- Power Query for data transformation
- CSV dataset (`hr_dataset_updated_clean.csv`)

## 🚀 How to Use
1. Clone this repository or download the files.
2. Open **HR_Analytics_Dashboard.pbix** in **Power BI Desktop**.
3. Load the provided dataset.
4. Refresh the data and explore the visuals.
